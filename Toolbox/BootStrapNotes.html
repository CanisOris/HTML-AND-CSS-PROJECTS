Bootstrap Local Installation Guide

A technical reference for mapping PowerShell setup steps to local project deployment and notes.

Installation Step PowerShell Command Action Performed Verification Method
1. Initialize NPM npm init -y Creates a package.json file to track project-specific configurations. A new package.json file appears in the Introduction-to-Bootstrap folder.
2. Install Bootstrap npm install bootstrap Downloads the framework locally without affecting global system paths. A node_modules folder and package-lock.json are created.
3. Git Ignore Setup echo "node_modules/" > .gitignore Generates a file instructing GitHub to ignore tracking the massive dependency folder. Running git status will not list node_modules/ as an untracked file.
4. Link Framework <link rel="stylesheet" href="node_modules/bootstrap/dist/css/bootstrap.min.css"> Connects the locally installed Bootstrap CSS framework directly into your webpage layout. Pasted into the <head> of index.html; page styling updates immediately.

Troubleshooting & Issues

Issue: Git Still Tracking node_modules After Creating .gitignore

Symptoms: After running echo "node_modules/" > .gitignore in PowerShell, running git status still shows hundreds (e.g., 509) of untracked files inside the node_modules/ directory.

Cause: When using the > or echo operators, Windows PowerShell defaults to creating text files using UTF-16 encoding. Git requires standard UTF-8 encoding to correctly read the contents of the .gitignore file. Because Git cannot read the UTF-16 file, it ignores your ignore rules.

Solution: Recreate the .gitignore file while explicitly forcing UTF-8 encoding using the Set-Content command.

Set-Content -Path .gitignore -Value "node_modules/" -Encoding utf8

Note: If you run git rm -r --cached node_modules and receive a fatal: pathspec 'node_modules' did not match any files error, it simply means Git had not yet staged the folder into its cache, so there was nothing to remove. Forcing the correct encoding is all that is needed.
